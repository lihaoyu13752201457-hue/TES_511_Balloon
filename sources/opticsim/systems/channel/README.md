data, and run products remain in the normal repo locations so tests and build
scripts do not need path changes.

## Interpretation

The default calibrated run is a Geant4 event-bookkeeping and detector-handoff
scaffold aligned to the headline 511-CAM optics numbers. It is not yet a full
wall-by-wall reconstruction of the original IDL channel ray trace.

The wall-by-wall reconstruction uses the public 30 nm W / 150 nm Si bilayer
geometry directly. Photons are sampled into the 150 nm Si spacer, W-layer
entry hits are rejected by geometry, wall hits are generated by the bent channel
shape, and each hit looks up W/Si `R/A/T(E, theta)`. It does not use calibrated
`n_bounce` or `theta_calibrated_rad`. The 20k default run in
`runs/channel_wallbywall_rebuild` gives a natural survivor mean of about 20 wall
bounces, consistent with the 17-38 reflection scale reported for the Shirazi
channeling lineage, but the resulting throughput is about 0.29 with Si path
absorption and about 0.59 without that absorption. This is a stronger physics
diagnostic than the calibrated scaffold, not a replacement claim for the
published 80% headline.

The diagnostic run applies paper bend angles and a one-time open-fraction loss.
Its lower throughput is intentionally retained as an audit of the remaining
channel path-model uncertainty.

`records/2026-05-21_channel_optics_plan_completion.md` is the current plan
checkpoint. It marks the public-geometry wall-by-wall Python line as complete
for the current stage, keeps the Geant4 channel line labeled as a
parameterized handoff rather than a full wall-by-wall geometry, and records a
1k detector-only Geant4 smoke driven by the wall-by-wall `phase_space.csv`.
The full optics+detector contract for that smoke run is `ok=true`.

`records/2026-05-21_channel_confidence_report.html` is the current presentation
report from physical principle to implementation. Its confidence split is:
high current-stage confidence for the conservative public-geometry Channel
model, but only medium calibrated confidence for the 80% headline until
original IDL/IMD provenance or an independent reflectivity export is available.

`records/2026-05-21_channel_independent_closure.html` is the independent
closure package. It confirms optical-constant/reflectivity closure using
CXRO/Henke-range checks, an electron-density 511 keV check, and an
IMD/DarpanX-equivalent Parratt recursion. It does not close the CAM511 80%
headline without an accounting gap: the best no-fudge public-geometry variant
in the current 10k scan is ideal roughness 0 nm with no Si path absorption,
`T=0.7615`; the literature-relevant 1 nm roughness/no Si path case is
`T=0.7369`.

Do not describe the current headline performance as a complete first-principles
prediction. It is a calibrated benchmark reproduction until the original
IMD/IDL wall-by-wall channel path and absorption/open-area accounting are
recovered.
