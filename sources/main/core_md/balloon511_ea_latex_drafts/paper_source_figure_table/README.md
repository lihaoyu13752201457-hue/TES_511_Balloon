# Paper Source Figure/Table Assets

This directory holds manuscript-facing figure and table assets that are copied
from validated simulation outputs or generated specifically for the LaTeX
drafts.

Current background-optimization story figures:

- `fig_mass_model_511_geometry.png`: manuscript Figure 1, rendered directly from
  the semantic OBJ/MTL export of the generated `Mass_model_511` geometry. The
  two panels show the full payload and a detector-bay cutaway from the same mesh.
- `fig_background_origin_story.{png,svg}`: reference selected-rate decomposition
  for prompt particles and delayed copper activation.
- `fig_optimized_shield_background.{png,svg}`: final S3d shield cross-section,
  cut-flow, and selected-background budget.
- `fig_optimized_mission_significance.{png,svg}`: final S3d cumulative
  significance and flux-threshold result.
- `background_optimization_story_provenance_20260713.json`: machine-readable
  inputs, checks, and values used by all four figures.
- `build_background_optimization_story_20260713.py`: regenerates the four
  manuscript figures and their provenance record.

Legacy mass-model figures:

- `fig_mass_model_xz_overview.png` and
  `fig_mass_model_detector_bay_detail.png` are older geometry-closure renders.
  They remain as provenance assets but are not the current manuscript geometry
  authority.

Current optics figures:

- `fig_optics_laue_transport_schematic.png`: radial--z Laue transport
  visualization generated from the current 10 m Ge(111) ring configuration and
  tracked accepted focal-plane crossings.
- `fig_optics_focal_crossings_xy.png`: transverse focal-plane crossing
  distribution accepted by the Be-window gate and used for detector replay.
- `fig_optics_generation_metadata.json`: input/output provenance and focal-spot
  summary for the optics figure generation.

Current detector-selection and time-axis figures:

- `fig_selection_veto_time_axis.png`: four-panel diagnostic generated from the
  current detector-selection, mission-time, and significance products for the
  M=50000 sampled-position chain. It
  shows line-window raw/active-veto/Compton-FoV rates, survival fractions, Compton/FoV
  class counts, and the mission-time fold with accidental live factor.
- `fig_compton_fov_geometry.png`: side-entry Compton/FoV geometry schematic
  generated from the selection Be-window disk center, normal, and radius, with the
  Compton kinematic equation used by the selection code.
- `fig_selection_veto_time_axis_summary.json`: machine-readable provenance and
  key values for the detector-selection figures.

Source note:

- The Figure 1 source of truth is the generated semantic `Mass_model_511` OBJ/MTL
  under `outputs/reports/Mass_model_511_stage_diam_300_300_300_350_350_400_20260701/`;
  the paper-facing PNG is a derived render, not a hand-drawn detector schematic.
- The background-decomposition inputs come from
  `engineering/geometry_optimization_20260704/42_geoopt_s3d_lightweight_20260712/data/reference_baseline_background_breakdown.json`.
- The final geometry comes from the retained S3d manifest under
  `engineering/geometry_optimization_20260704/43_geoopt_s3d_o8_fallback_20260712/`.
  The manuscript cut-flow, component budget, and mission curve use the later
  pixel-level 420 eV FWHM response closure in
  `engineering/ea_detector_response_closure_20260713/`; that package also proves
  exact reproduction of the response-off Step05/Step08 authorities.
- If any of those authorities are regenerated, rerun
  `build_background_optimization_story_20260713.py`, inspect the figures, and
  recompile both LaTeX drafts.
- The optics figures are generated by `build_optics_figures.py` from the current
  10 m Ge(111) configuration and its tracked diffracted focal-plane
  crossings. If the optics inputs are regenerated, rerun that script and recompile
  the LaTeX drafts.
- The detector-selection figures are generated by
  `build_selection_time_axis_figure.py` from the current M=50000
  detector-response summary, background time-variation CSV, and
  cumulative-significance CSV. If these products are regenerated, rerun that script
  and recompile the LaTeX drafts.
