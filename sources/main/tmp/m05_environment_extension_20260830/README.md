# M05NEW 数据替换包

本目录只服务于把M05原稿更新到当前单能大气511 keV通量闭合结果，不扩展新的论文主题。

## 当前发布状态：HOLD

PARMA源、输运曝光、事件权重、五锚点与81节点时间折叠的数值链均已闭合；但新纳入的
弥散单能线揭示出A/B光学接受度并不匹配。质量模型A采用半径约1.898 cm的入口包络和
624-copy W多孔准直结构，当前质量模型B则采用半径2.70 cm的窗口及无多孔网格的四边W框。
因此下列B数值只属于当前开放四边框的完整设计，不能支撑稿件中“相同入射孔径、受控变化仅为
焦面与冷端相对位置”的因果表述。最终图表、双语PDF和结构化发布暂停，直至选择以下其一：
（1）把B明确写成同时改变焦面、BGO、入口和准直结构的整体替代设计；或（2）构建并输运与A
物理准直接受度匹配的B。当前开放四边框B的3-sigma Gaussian Fmin
`4.185157715646857e-05 ph cm^-2 s^-1`保留为条件结果，不作为受控A/B终稿值。

## 当前结论

- **数值闭合完成**：源构造严格采用“宽带总量−粗分箱线面积+单能线”，没有把单能线响应
  直接加到仍含相同线面积的宽带gamma上。宽带参考通量为`4.7996615777852`，移除粗分箱
  线面积`0.17644263123359388`，去线连续谱`4.623218946551606 ph cm^-2 s^-1`。
- 单能线能量为`510.99895 keV`。day-15全空间积分通量
  `0.16651547160226118 ph cm^-2 s^-1`和80个等mu角分量均来自同一大气状态下的PARMA
  专用线参数化；Mahoney/Harris文献只支撑该湮没线成分的存在和物理背景，不用于数值归一。
- 质量模型A的day-15最终本底为`0.060595953980508585 cps`，20 d累计本底为
  `99923.14165545377 counts`；3σ Gaussian/Asimov Fmin分别为
  `(5.79993 ± 0.39118)×10^-5`与`(5.80909 ± 0.39119)×10^-5 ph cm^-2 s^-1`。
- 质量模型B的day-15最终本底为`0.03122834776990912 cps`，20 d累计本底为
  `54805.970088911905 counts`；3σ Gaussian/Asimov Fmin分别为
  `(4.18516 ± 0.15629)×10^-5`与`(4.19409 ± 0.15629)×10^-5 ph cm^-2 s^-1`。
- 质量模型B保留质量模型A的`99.75%`有效面积；day-15本底和20 d累计本底分别为A的
  `51.54%`和`54.85%`，3σ Gaussian Fmin改善`1.3858×`（约`1.39×`）。
- 单能线选后统计为：A `12`个、任务积分ESS `11.9999964`；B `186`个、任务积分ESS
  `185.899883`。B在完成最小必要增量后，线项Fmin方差占比`0.4991417`、线sigma/其余
  sigma比`0.9982849`，均低于预设上限；A/B最终结论均为`NO_TOPUP`。
- 当前误差包含有限输运模板、五锚点回放、信号Aeff和偶然符合探针统计；PARMA物理通量/
  角分布、几何、响应模型和跨分量运输系统学均未纳入。

## 论文逻辑

保留一条紧凑主线：`质量模型A可审计基线 -> 本底限制诊断 -> 质量模型B优化几何 ->
同源、同响应、同选择、同任务轴可行性比较`。质量模型A只承担参考和工程因果，不扩写成
第二套主结果；论文主结论仍是质量模型B。

源级有一个必须显式保留的边界：去线连续谱形状使用W=118.3、g=0参考和既有trajectory
gamma缩放，物理单能目标使用W=114.6、g=0.15及逐节点Rc/depth。该混合闭合没有重新生成
一套所有分量都处于单一参数状态的宽带场。

## 状态含义

- `READY`：数值已闭合，可直接用于改稿。
- `READY_RETAIN`：用户指定保留现有图像或表述，不由本次数值包覆盖。
- `LIMITATION`：必须在解释结果时保留的模型或误差边界。
- `PENDING_BUILD`：数值已就绪，但双语TeX/PDF仍待最终编辑、编译和哈希。
