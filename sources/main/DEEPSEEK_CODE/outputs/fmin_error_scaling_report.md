## 2. 扩增模型

- 现 gamma INSTANT：12.98M 主粒子 / 32 job / 6.29 GB → 1 个 W2 幸存者（权重 0.004183）
- 幸存者数 ∝ 主粒子数（W2 通过率 ~7.7e-8/主粒子，Poisson）
- N_eff(Np,M) = W² / (w_p²/Np + w_d²/(44.25·M))，W=0.007808
- gamma 权重 = 1/ΣTT 自动随统计稀释；物理率不变
