   371	and then applies the same first-cone intersection test to the first reconstructed
   372	scatter. If no valid sequence is found, the event is classified as
   373	unreconstructed. Such events are retained in the baseline selected-rate
   374	definition but are not called field-of-view passing. The line-window result
   375	therefore does not gain sensitivity from rejecting ambiguous reconstruction
   376	failures. This policy is not a conservative lower bound on the net sensitivity:
   377	in the current $\wii$ sample, a single-site-only diagnostic alternative that
   378	vetoes all multi-site candidates would retain $59.4\%$ of the focused signal
   379	and $68.2\%$ of the selected background, reducing the simple $S/\sqrt{B}$
   380	figure to $0.720$ of the baseline value. The baseline selection therefore treats ambiguous
   381	multi-hit events as a reconstruction-model boundary that must be validated, not
   382	as a sensitivity gain from aggressive event rejection.
