   270	coordinate correlations; the production-position construction keeps them in
   271	the source before detector transport.
   272	
   273	The delayed-decay source is therefore launched from sampled production
   274	positions rather than from an axisymmetric profile. Let row $j$ of the
   275	weighted production table carry activity weight $w_j$, with total activity
   276	$A=\sum_j w_j$. The construction draws $M$ production positions with
   277	replacement using probabilities $p_j=w_j/A$ and assigns each sampled point
   278	source the flux $A/M$. The expected activity assigned to row $j$ is then
   279	\begin{equation}
   280	  \mathbb{E}\!\left[N_j\frac{A}{M}\right] = M p_j \frac{A}{M} = w_j ,
   281	\end{equation}
   282	so the estimator preserves the total activity and is unbiased for the weighted
   283	spatial distribution. Here $M$ is the number of equal-activity sampled point
   284	sources, a sampling size rather than the number of physical production rows.
   285	The reference delayed source preserves the fixed total activity at the
   286	source-definition level and is replayed through the same detector/cryostat
   287	geometry as the prompt stream; the nominal calculation transported $10^{6}$
   288	delayed decays, and the corresponding Cosima live time is a transport record
   289	for the generated decay sequence, not a physical balloon exposure.

   319	\subsection{Detector event selection and veto definition}
   320	\label{sec:selection}
   321	
   322	The analysis window is
   323	\begin{equation}
   324	  \wii = [510.79,511.21]\keV,
   325	\end{equation}
   326	corresponding to $511\keV\pm210\,\mathrm{eV}$. This window is matched to a sub-keV TES response assumption and is narrow enough to suppress continuum background while retaining most of the line response.
   327	The quoted flux thresholds therefore apply to a line whose intrinsic width remains small compared with this analysis window after detector response; broader source lines would require convolving the source line profile with the detector response and re-optimizing or widening the analysis window.
   328	
   329	The detector selection has two explicitly separated veto layers. First, an
   330	active anticoincidence gate is applied on a common detector time axis. For a
   331	candidate group $c$, formed from event instances separated by no more than
   332	$\tau=1\,\mu\mathrm{s}$, the TES energy and active-shield energy are
   333	\begin{equation}
   334	  E_{\mathrm{TES}}^{(c)}=\sum_{j\in c}E_{\mathrm{TES},j},\qquad
   335	  E_{\mathrm{sh}}^{(c)}=\sum_{j\in c}E_{\mathrm{sh},j}.
   336	\end{equation}
   337	A candidate enters the hard line window if $E_{\mathrm{TES}}^{(c)}\in\wii$,
   338	and it passes the active shield if
   339	\begin{equation}
   340	  E_{\mathrm{sh}}^{(c)} < E_{\mathrm{veto}}, \qquad E_{\mathrm{veto}}=50\keV
   341	\end{equation}
   342	for the baseline CsI configuration. The shield sum is evaluated from the CsI
   343	active-shield volumes in post-processing. Native detector trigger/veto blocks
   344	are present in the geometry description, but the quantitative rate definition is
   345	this common post-processing definition, so prompt, delayed, and focused-signal
   346	streams use the same coincidence window and threshold.
   347	
   348	The second layer is a topology/field-of-view consistency test on the TES hits
   349	that survive the active-shield gate. Baseline event classes are kept explicit:
   350	single-site events, valid reconstructed multi-site events, and unreconstructed
   351	multi-site events. Single-pixel TES events are retained as calorimetric line
   352	candidates. For a two-hit event, both possible first-scatter orders are tested
   353	under the assumptions of a single Compton scatter followed by full absorption
   354	in the measured TES hits. For an assumed order with first deposited energy
   355	$E_1$ and remaining scattered-photon energy $E_{\mathrm{sc}}$, the kinematic
   356	angle is computed from
   357	\begin{equation}
   358	  \cos\theta_C =
   359	  1 - m_ec^2\left(\frac{1}{E_{\mathrm{sc}}}
   360	  - \frac{1}{E_1+E_{\mathrm{sc}}}\right).
   361	\end{equation}
   362	The event is kept if either order gives a physically valid first-scatter cone
   363	that intersects the side Be-window disk. For higher multiplicities the current
   364	implementation enumerates candidate hit orders up to six TES hits, selects the
   365	best sequence using the unweighted Compton sequence residual
   366	\begin{equation}
   367	  Q = \sum_{i=1}^{n-2}
   368	  \left(\cos\theta_{C,i} -
   369	  \hat{\mathbf u}_{i-1,i}\cdot\hat{\mathbf u}_{i,i+1}\right)^2,
   370	\end{equation}
   371	and then applies the same first-cone intersection test to the first reconstructed
   372	scatter. If no valid sequence is found, the event is classified as
   373	unreconstructed. Such events are retained in the baseline selected-rate
   374	definition but are not called field-of-view passing. The line-window result
   375	therefore does not gain sensitivity from rejecting ambiguous reconstruction
   376	failures. This policy is not a conservative lower bound on the net sensitivity:
   377	in the current $\wii$ sample, a single-site-only diagnostic alternative that
   378	vetoes all multi-site candidates would retain $59.4\%$ of the focused signal
   379	and $68.2\%$ of the selected background, reducing the simple $S/\sqrt{B}$
   380	figure to $0.720$ of the baseline value. The baseline selection therefore treats ambiguous
   381	multi-hit events as a reconstruction-model boundary that must be validated, not
   382	as a sensitivity gain from aggressive event rejection.
