# 活化时间索引、生产库存及响应修复报告

2026-09-25。本轮按用户“修复吧那”执行。**已修复已确认的时间索引错误，重建保留样本的受影响生产库存，并完成缺失链响应及两构型时间积分重算。论文尚未修改。**

## 1. 修复了什么

原 `MCSteppingAction.cc` 用次级粒子向量的第0项计算衰变时差；该位置可能属于当前离子较早减速步骤产生的电子。现在改为“全部次级数减去本步新次级数”，只取本次衰变产生的粒子。此前360次旧/新诊断已经复现旧误判并验证这个修正；本轮另编译了只包含该索引修改的生产程序，原子体排队行为保持不变。

补丁不是停留在建议层面：本轮位置核验与响应补算实际使用了修复后的独立程序。原安装依工作区只读约定保留；今后的普通生产应使用 `runtime/production/cosima` 或将最小补丁审定后应用到安装源码。逐核态补算专用的 `runtime/cosima` 同时沿用前轮“解析库存负责后续子体”的分工，两者用途在README中分开列明。

核对两构型实际保留的全部246份生产文件，覆盖15,367,941个原初事例、36.34 GB压缩数据。逐文件核对事例数、RP储存数、DAT校验值和源模式；没有扫描其他TB级历史数据，也没有重新产生大气粒子。

| 库存处理 | 下置 | 侧置 | 合计 |
|---|---:|---:|---:|
| 恢复最早的遗漏长寿命母核 | 128 | 395 | 523 |
| 移除同一链误存的后代RP | 5 | 7 | 12 |
| 未解决的核态身份或后代关联 | 0 | 0 | 0 |

每条恢复记录保留母核、停止位置、原始相互作用祖先、所属生产任务和粒子族曝光。原来11条被排除的激发态全部找到对应母核并纳入替换；另有一条F-21基态后代需要从原始库存移除。

11条激发态原先未进入被输运的基态源库，F-21的这一位置也未被旧确定性源抽样选中。因此，12条后代的移除改变原始生产库存，但没有可从旧响应目录直接扣除的已抽样记录。代码已经逐位置检查，未任意删掉其他位置的同种核素，也未把残余源率重新放大。恢复母核按本粒子族全部生产TT归一化，再演化各自子体，避免母核和后代重复计入。

523个恢复位置全部通过独立几何核验，核素身份、体积及材料符合预期。原相互作用位置的保存精度为约10⁻⁵ cm。原始随机衰变时刻被归零，不能逐条恢复；这些母核最短平均寿命约0.029 s。对全部受影响核态生产记录按原指数寿命评估，真正短于1 ns的期望记录数合计约5.3e-06，这是恢复时采用的可量化近似。

还逐卡核对了下置1,100份、侧置646份实际瞬时本底源卡：均采用 `Ignore`，不依赖这个时间判据。本次没有把生产阶段的错误误归因于瞬时本底污染。

## 3. 补算及验证

本轮按预先固定的构型/材料分层补算16万次有效衰变，各构型8万次，粒子族分别归一化。另有523次位置检查。

种子核验发现程序未采用源卡中的Seed，最初同时启动的三个池共4万次记录用了相同默认种子。这些记录已全部隔离，改用命令行明确传入不同种子重算；其他池的实际头部种子各不相同，已如实入账。因此，本轮实际启动200,523次输运，进入响应结果的仅160,000次，没有混入被排除记录。

所有有效响应逐事例核对INIT、位置、核态、几何、事件数及种子；零沉积事例仍在固定N分母内。沿用500 eV单像素FWHM、50 keV主动BGO阈值、1 μs分组、连续康普顿轨迹/信号spot判定及实际像素几何，塑料闪烁体不参与分析。

下置新增5个最终选中事例，来自O-15、Mg-23和C-11，其第15天增量为(0.000267225 ± 0.000126) s⁻¹。侧置新增零个选中事例，不能据此认定该部分物理本底为零。

新旧响应目录的原有数组、81节点因子、信号目录和瞬时本底统计均逐项一致；新增选后权重之和恰好等于直接延迟率增量。两构型分别完成第0、5、10、15、20天各200,000 s的三路物理泊松时间轴，并在81节点上积分20天，未使用额外单信号探针。

## 5. 仍需保留的误差范围

本轮四个预定分层中，完全零选中分层的联合95%直接率上限之和分别为下置0.000214 s⁻¹、侧置0.000338 s⁻¹。选中分层的统计误差另列。将前轮8个分层与本轮4个分层统一作12分层多重性处理后，相应零分层总上限为0.00156和0.000869 s⁻¹，见独立JSON。它们是补算响应零计数的直接率上限，不是所有瞬时零分量或非线性时间叠加的统一上限。

W-176源率未因这523条恢复而改变。将修复后的全部响应率代入此前已知低能级分支上界，20天通量的最大相对影响仍仅约下置0.048%、侧置0.035%。未编造未知绝对EC馈入强度；这个界限仍不覆盖未观测高能级馈入等其他核模型问题。

保留大气生产样本自身的有限统计、旧源位置抽样误差及其他核/输运模型系统误差，不因本轮错误修复自动消失。本轮解决的是已证实的索引错误及其在保留生产记录中的可恢复影响，没有以重跑全部生产来替代审计。
